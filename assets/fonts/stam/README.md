# גופני סת״ם לתצוגת פרשיות תפילין

בעל הפרויקט מסר ב־2026-10-14 שקיבל אישור מהיצרן להשתמש בכל הגופנים,
והורה לשלב את הקבצים הנוכחיים. הגופנים כוללים קווי מתאר וקטוריים.

- בית יוסף והאר״י: קווי מתאר מתוך התיקונים שסופקו; בהאר״י נשמרה גם
  רגל הקו״ף המנותקת. הופקו קובצי OpenType עם מיפוי עברי.
- ספרדי: `StamVaalish-Regular.ttf`, הקובץ שסיפק בעל הפרויקט ללא שינוי.
- חב״ד: גליפים מהגופן המוטמע בדף הא״ב בחוברת שסופקה,
  `StamAlterebbeReuvensofer-regular`, עם ייחוס המקור
  `Stam Alterebbe Reuvensofer Romi brener`. הנקודה הלבנה הזעירה בת״ו
  מולאה לפי הוראת בעל הפרויקט; קווי המתאר החיצוניים והפרופורציות נשמרו.

אלה נכסי תצוגה. אין בהפקה ובהתאמה טענה ליצירת צורות האותיות המקוריות
או הענקת רישיון נוסף לצדדים אחרים. גופן חב״ד הנוכחי יוחלף בגופן
שהיצרן ישלח. משפחת התצוגה `StamChabad` ומזהה הכתב `chabad` יישמרו;
החלפה אינה משנה את הנוסח או את ההתקדמות ברשומות המשתמש.
