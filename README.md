# סופר ומונה

תוכנה חינמית לסופרי סת״ם. מודדת את זמן הכתיבה, סופרת שורות ועמודים,
ומחשבת שכר לשעה, רווח נקי וצפי סיום — מתוך העבודה שנרשמה בפועל.

**גרסה 0.4.0** · אנדרואיד 7.0 ומעלה · ווינדוס 10 ומעלה

---

## הורדה

הקובץ להתקנה נמצא תחת [Releases](../../releases).

**אנדרואיד:** להוריד את קובץ ה-`apk` ולפתוח אותו. אנדרואיד יבקש אישור
להתקנה ממקור שאינו החנות — זו אפליקציה שמותקנת ישירות ולא דרך Google Play.

**ווינדוס:** להוריד את קובץ ה-`zip`, לחלץ, ולהריץ את הקובץ שבפנים.

---

## מה היא עושה

- **מדידת זמן כתיבה** — שעון שרץ ברקע, גם כשהתוכנה סגורה, עם הפסקות שאינן
  נספרות בממוצע.
- **מעקב אחר מיקום** — באיזה עמוד ובאיזו שורה אתה נמצא, בספרות עבריות.
- **לוח תכנון** — באיזה עמוד להיות בכל יום, מדלג על ימים שאינך כותב בהם.
- **כסף** — מחיר, הוצאות, הגהה, תשלומים שהתקבלו, ורווח לשעה לפי הקצב האמיתי.
- **דוחות** — חודשי ושנתי, כולל דוח לרואה חשבון לפי שנת מס לועזית.
- **לוח עברי מלא** — תאריכים, ימי עבודה, וזמני מעבר יום לבחירתך.
- הכל נשמר במכשיר בלבד. אין הרשמה, אין תשלום, ואין צורך בחיבור לאינטרנט.

## בנייה מהמקור

דורש [Flutter](https://docs.flutter.dev/get-started/install) 3.38 ומעלה.

```bash
git clone https://github.com/soferstam-app/sofer-vmone.git
cd sofer-vmone
flutter pub get
flutter run
```

לבניית קובץ התקנה:

```bash
flutter build apk --release      # אנדרואיד
flutter build windows --release  # ווינדוס
```
