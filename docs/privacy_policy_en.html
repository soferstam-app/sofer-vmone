Introduction

"Sofer v'Mone" (the "App" or "we") is an open-source application developed to help Sofer Stam manage and track their work. We respect your privacy and are committed to protecting your personal information.

Where Your Data Goes

Nowhere. Everything you record stays on your device. There is no account, no sign-up, and no server holding your work.

Backup is one file, and it is yours

The app writes a file and you decide what happens to it: keep it on the device, send it to yourself, or drop it in a folder you already back up. The app uploads it nowhere and does not know what you did with it.

The only request it makes

When you press "check for updates", the app asks GitHub whether a newer release exists. That is the only request it makes, and only when you press it. GitHub sees an IP address and a user agent, as any website would. Nothing about your work is sent.

Google Drive sync has been removed

Versions up to 0.3.x offered Google Drive sync. It was removed in 0.4.0: it needed a sign-in, permissions and tokens for what one file does without them. The app no longer requests access to a Google account, holds no tokens, and does not contact Google services at all.

What Data Do We Collect?

The App stores the following data on your device only. It does not collect it, send it, or see it:

  • Projects: Project name, type (Torah/Tefillin/Mezuzah), price, expenses, goals, client email, target date
  • Work history: Date and time, work duration, pages/lines written, description
  • Settings: Notification preferences, day rollover time, work day settings
  • Google account info: Email address (for identification and display only)

Important: The App does not collect additional personal information, does not track location, and does not use analytics or advertising tools.

Your Rights

As a user, you have the following rights:

  • Access: View all your data at any time (in Summary and Projects screens)
  • Edit: Edit or delete any data (projects, work records)
  • Delete: Delete all data (Reset All Data button in Projects screen)
  • Export: Data is stored in open JSON format, and all of it can be exported to a single file at any time

Data Retention

Data is retained as long as you use the App. When you delete a project or record:

  • The item moves to Recycle Bin (soft delete) and is kept for 30 days
  • After 30 days, it is automatically removed on the next sync
  • You can permanently delete from the Recycle Bin at any time

When you uninstall the App:

  • Local data is removed from the device
  • Any backup files you saved remain yours, wherever you put them
