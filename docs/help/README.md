# תוכן העזרה המובנה

התוכנה טוענת את `FAQ.he.json` כ־asset מתוך מסך העזרה המקורי של Flutter.
התוכן זמין ללא חיבור לרשת.

## תחזוקה

- `FAQ.he.md` הוא מקור התוכן לעריכה, עם מזהים קבועים לשאלות.
- `generate.py` יוצר ממנו את `FAQ.he.json` וגם תצוגת HTML מקומית.
- `FAQ.he.html` הוא תוצר תצוגה מקומי ואינו חלק מהמאגר.

לאחר עריכת המקור, מריצים משורש הפרויקט:

```text
python docs/help/generate.py
```

יש לשמור את מקור ה־Markdown ואת ה־JSON שנוצר יחד. מזהי שאלות משמשים
לקישורים פנימיים; יש לשמור עליהם כשמשנים ניסוח. קובץ ה־JSON נכלל
ברשימת הנכסים ב־pubspec.yaml.
